# Hisobchi — калькулятор зарплаты и налогов (Узбекистан, 2026)

Мобильно-адаптированное веб-приложение для малого бизнеса и ИП:

- Калькулятор Gross ↔ Net: НДФЛ 12%, ИНПС 0,1% (за счёт НДФЛ), соц. налог работодателя (12% / 25% / своя ставка), итог на руки и затраты работодателя; месяц/год.
- Календарь налоговых сроков с переносом с выходных и праздников и экспортом напоминаний в `.ics`.

Стек: Vite, Tailwind CSS, ванильный JS. Логика расчёта находится в `src/lib/tax.js` и покрыта тестами.

```bash
npm install
npm run dev      # разработка
npm test         # юнит-тесты (vitest)
npm run build    # статическая сборка в dist/ (подходит для Netlify, Vercel, GitHub Pages)
```
